# Drawbridge v5.5

Refines light mode with a darker drawing canvas and clearer separation between the workspace, sidebar, and panels. Sidebar and document-tab borders are thinner. The heavy gray sidebar strip is removed while retaining the generous drag target for resizing navigation.

The existing dark palette and v5.4 markup-saving fixes remain included. The production build and light-mode interface were checked locally; the release workflow runs the regression suite before signing and Apple notarization.
