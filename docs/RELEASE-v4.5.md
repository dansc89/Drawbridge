Drawbridge v4.5 makes the active markup tool clear with a blue background and white icon. The highlight follows toolbar clicks and keyboard shortcuts across all eight tools, and turns off when markup controls are unavailable.

This release also fixes shallow text boxes saving with empty appearances. Text now retains visible vector glyphs when opened in other PDF viewers, including Apple Preview. Text layout stays clipped inside the annotation; original page contents and geometry are unchanged.

Validation includes manual creation of rectangles, ellipses, lines, arrows, filled polygons, polylines, and inline text using their shortcuts; selection, moving, text editing, deletion, undo/redo, saving, and visual review of the saved PDF in Apple Preview. Regression tests cover active-tool selection and shallow text appearance visibility, alongside existing PDF preservation, navigation, OCR, hyperlinking, flattening, and reduction checks.

The app and DMG are Developer ID signed, notarized, and stapled by the release workflow.
